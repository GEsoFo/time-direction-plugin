# 通用择日神煞覆盖与校订

本版登记 150 项规则（既有贵登天门、五不遇时、两德、建除和十二值神继续保留）。范围由用户确认：先补通用择日，暂不纳入修造二十四山、飞宫九星及完整出生八字相主。

年方是方向取值，不直接变成值日或值时凶吉。月神用节月，四时用节月分季；月忌、反支用农历日；四离四绝等用公历整日。

以下同位异名合列，当前命中取值由规则模块计算。具体事项仍由模型裁决；没有通用分数或自动大吉。

## 关键校订

- 天愿、地囊：用原书按语校订表，旧表留在来源原文中供核对。
- 王官守牢：王取四孟、官取四仲，守日辰未戌丑、牢日酉子卯午。
- 天火/月灾煞：寅月子起，逆行四仲；天狱与灾煞同源，不再重复计入。
- 阴阳不将：六月戊午为逐阵，已经剔除；小会二月己卯、八月己酉，阴道冲阳取相反两日。
- 厌建类的阴位、三阴、阴道冲阳依原书末段按语标日神关系，没有伪造月宿计算；被删所领日、绝阴绝阳所领日未回填。
- 八专：采用卷五五日表，不混入后世八日表。鸣吠13日、鸣吠对11日采用原书后引校订说。
- 九神（要安等）：按照原书九神总论说明祭祀用途，不照抄前引笼统修造上表宜忌。
- 九丑：候选日与真九丑时段分开；真格须按所选月将加时后大吉丑临四仲。
- 无禄：先标日禄落旬空候选，年月太阳填实与否由模型核对，不能列出十日就概断凶。
- 天德：本项目既有四仲月借支表保留；原书四维方与借支争论不借本次扩充暗改。
- 土王：采用四立之前18个公历整日的具名口径，不声称古历余分推算已实现。

## 来源与复现

《协纪辨方书》卷三至八原文保存于 sources/，每条规则带可打开的来源链接和起例。土王依据《田家占候集览》卷十，原文摘录在 sources/tianjia-10.txt。

`scripts/test_calendar.py` 验证既有规则与安全渲染；`scripts/test_shensha.py` 验证校订表、分类范围、合法干支、历日/晚子边界、月朔反支、土王和真九丑；导出的 JSON 附完整神煞目录与展开依据。
