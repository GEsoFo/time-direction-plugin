# 联合方向系统（2026-10-07）

奇门采用具名时家转盘拆补法，天禽寄芮，中五寄坤二；星门转八宫，八神阴阳顺逆。局表取《协纪辨方书》卷35，三元按最近甲己符首的支分上中下元。页面与 MCP 可选拆补或置闰，两法保留独立数据及判断上下文，不等同飞九宫法。

置闰采用《遁甲演义》“超神接气置闰诀/超接引例”口径：符首每五日一元；芒种、大雪含符首起算达到九日时，三元完后重复该节三元十五日。接气时新节已至而上元符首未至，借新节下元；闰奇期间保持重复节三元。起算正授是历法核得1899-12-07甲午大雪日，连续推至请求日期，支持1900至2099；不把每年节气最近甲己日当独立置闰锚点。采用北京时间所选23时/00时换日，节气准确时刻用于借下元，九日阈值按民用日序含首尾数。其他阈值/派法须另选命名配置，不能混同。来源：https://zh.wikisource.org/zh-hant/遁甲演義#超神接氣置閏訣 。

日历格只显示当日中午所属日柱和月令的值日神煞，不将时煞或晚子翌日命中汇为“部分”。时辰图保留时煞、贵登、罡塞、不遇和交节/换日明细。奇门九宫南上北下，神最上，左列星上门下，右列天盘干上地盘干下，寄干同行区别。

《遁甲演义》卷2天遁定义丙、生门、地丁；其阳四局乙酉时坎一、阴六局庚申时离九两例用于独立验证。龙遁主式为乙、休、坎；另说乙休加癸带伏吟文字歧义，只标条件候选。虎遁歌诀式为天乙地辛休门艮八，又说乙生辛，一云辛生艮，分别登记。墓迫、击刑、旬空及乙加辛青龙逃走等冲突并列，不用格名自动定吉。

六壬贵人方是当前昼夜贵人所临地盘，不是时支见贵；还须核贵神旬空、贵人落地旬空及全部本命。式盘斗柄以月将加时找天盘辰所临，按《六壬大全》卷4“斗柄所指”保留原兵机事类，不称真实北斗七星。
