规则口径、覆盖范围与来源

年柱在立春准确时刻换年，月柱在节换月；日柱换日口径见上方说明。月将与月建分别计算：月将只按中气准确时刻换将，月建按节准确时刻换月。昼贵与夜贵按显式选定表计算；不同口径切换后，原有模型判断自动失效。

覆盖：太岁、岁破、年/月三煞、月建月破、建除、日时十二值神、天德月德及合、日禄日马、天乙、日旬空、贵登天门、五不遇时；四柱两两五行生克、天干五合、地支六合六冲刑害破、完整三合三会、藏干。三合六合只标关系，不直接判合化。月破与建除破标注同源。新增《协纪辨方书》通用年方、月神、四时、日时和历日规则，详见当前时段的全部起例清单；同位异名合列，旧表与校订注明。修造二十四山、飞宫九星和完整出生八字相主属于另选的专门体系。

宝光是十二值神序列第六位的名称，用来区别月度天德神。未调用黄历“宜忌”接口；页面无内置 API 密钥。

来源：《协纪辨方书》卷七、卷三十二贵登天门定局、卷三至卷六神煞起例；节气历法使用 lunar-python。六壬常用贵人表为独立传统口径，不与协纪表混用。

使用 MCP：输入“用择时与方位 MCP 为［年份或日期范围］的［事项］择日，本命［各参与者地支］，用方［地支或未指定］，并回填日历”。计算通过 time-direction 服务，模型按配套工作流判断；空白事项只显示事实。
