# 事项裁决

读取每窗 facts、target_relations/direction_candidates、judgment_criteria。用代码给出的完整天地盘、四课三传和旬空；不要凭记忆重排。事实与事项适用性、模型取舍分别说明。

先看直接影响核心对象的关系与事项专门条件，再看月令四柱、各本命及用方、德神建除黄黑道，最后结合特殊格局；这是工作框架，不是古书统一排名，可按事类调整并说明。多个本命逐人核对，再比较参与者关系；见合不等于合化，月破与建除破同源不重复计权。黄黑道不一票否决，贵登不自动消掉不遇或冲命。

年/月方位神不是全天禁令；月/季节值日神不能搬作时神。日德/日禄分所取支、天盘落地、时支相见，时支见德不等于德入传或发用。神煞候选按原条件继续核真九丑、禄落空等附加条件。

罡塞鬼户为天盘辰加地盘寅，不要求入传；按原文避难、私祷、吊丧问病、合药书符等事类核适用性，不泛称大吉。逐窗口读取 judgment_criteria 中甲戊庚日、辰将、实际昼贵等组合限制。中气准确时刻换将，卯酉昼夜非当地日出日落。

奇门两法使用所选 context.qimen_method，格局主式、另说和条件候选分别处理。龙遁休乙加癸含伏吟文字歧义，不冒称完整另说；虎遁主式/生门另说分列。门迫、击刑、三奇墓、旬空、乙加辛等冲突同时核对。格局原始事类与用户事项不同需说明推理，不凭名称断吉。

六壬贵人方取贵人所临地盘，核贵神空/落地空及全部本命，不一律选贵人宫。式盘天盘辰斗柄是传统兵机符号方，与真实七星地平坐标分开。真实星空考虑快照时刻、太阳高度、地平线；天气遮挡未实测不臆称可见。

用方为空时，对优先/可选窗口比较十二支候选，用 selected branch、具体 reason、事实 evidence 回填 suggested_direction。避用/待定解释为何无推荐方向，不用转向抵消时段直接冲犯。只给本命支的适用范围限定于支层关系。
